>
> 按 「停止解析」（或解析中途掛掉）之後，還沒出現的品名、有效日期、廠商名稱會 補成空白列。已經抽出的欄位照留，不會被蓋掉。）

9. - [x] 後端偶爾會出包，解析跑到一半掛掉的情況是有的
>
> 從首頁，選取欄位及測試速度的地方下去修改「測試情境」

## README 順便回答五件事

1. 這份需求哪裡沒講清楚？你是怎麼假設的？

> 1. 需求4, 經過詢問已獲得較爲詳細資訊。

1. **這個介面上，你決定不顯示、或降級顯示哪些資訊？為什麼？**

> 「把握度百分比」"confidence"：
> 不顯示數字，0.51 跟 0.44 對使用者沒有差別，差別是「要不要多看一眼」

1. **這幾條需求裡，你覺得有哪兩條互相衝突？你怎麼取捨的？**

> 需求4,5 衝突，如果做 "切頁會跟「同組一起看」打架。"

> (4) 欄位數量不固定。十幾個是常態，但也遇過上百個的
> (5) 欄位分成幾個群組（基本資料／營養標示／檢驗結果／廠商資訊），同一組的要能一起看。
